# PropBuilder Player

Native cross-platform player for [**PropBuilder**](https://propbuilder.noxelstudio.com) projects.

PropBuilder is a no-code builder for creating fictional apps and user interfaces used as on-screen graphics in movies and TV shows — fake messaging apps, dating profiles, social feeds, investigation screens and other believable interfaces for film and television productions.

This repository contains the **Tauri-based native player** that displays those interactive fake app screens (mobile, tablet, laptop) in fullscreen, offline. It builds for **macOS, Windows and Android** via GitHub Actions.

## Links

- 🌐 **Website / editor:** https://propbuilder.noxelstudio.com
- 💸 **Pricing:** https://propbuilder.noxelstudio.com/tarifs
- 📱 **PropBuilder Viewer (iOS, free):** https://apps.apple.com/app/propbuilder-viewer/id6766218598

## What it does

- Opens any PropBuilder project bundle and plays it like a real app
- Fullscreen, touch-first, works offline
- Page navigation, hotspots, swipe gestures, transitions and frame-by-frame animations
- Native builds for desktop (macOS / Windows) and Android

## Build

Native builds are produced through the GitHub Actions workflows in [`.github/`](.github/). See the workflow files for the exact inputs and signing setup.
